Legend · 01 Spatial analysis

Reproducible GIS pipelines around Toronto

Each project keeps raw data out of git, logs every filter, and reports both the result and the method's bias.

  • Food Program Accessibility, Mississauga

    Who lives more than a 500 m walk from a food program? Compares a straight-line Euclidean buffer with a 500 m network service area along the walkable street graph. The gap between the two is reported as a finding in itself: the optimism bias of container-based accessibility.

    Python
    GeoPandas · OSMnx 2.x
    Census population

  • Noise Exposure, Toronto Pearson Airport

    Maps aircraft noise contours around YYZ, estimates the population inside each contour band, and explores how flight operations relate to measured noise in the surrounding communities.

    R · Python
    Spatial statistics
    StatCan boundaries

  • Aircraft overflight exposure in Toronto private · in progress

    Infers Pearson's daily runway configuration (west flow or east flow) from ADS-B tracks and joins it to a 2021 census-tract daily panel. Pre-registration stage: outcome and exposure definitions live in config files, never in code.

    Python · DuckDB
    OpenSky Trino
    EPSG:3347

Legend · 02 Tools

Small programs that do one thing

  • U of T Course Finder

    Searches the UTSG, UTM and UTSC academic calendars by keyword from the terminal. Outputs a table, JSON or CSV. Standard library only, so nothing to install.

    Python 3
    CLI

  • Chinese ID Checksum Tool

    Calculates and validates the 18th checksum character of a Chinese resident ID number using the official weight table and mod-11 mapping.

    C++

  • IdCardTest

    Console validator for Chinese ID numbers: length, digit check, strict birth-date parsing and checksum. Chinese-language README.

    Java
